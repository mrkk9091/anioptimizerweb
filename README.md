# [AniOptimizer Website](https://mrkk9091.github.io/anioptimizerweb/)

This is the source code for the official **AniOptimizer** landing page — a modern, single-page application built with vanilla HTML, CSS, and JavaScript.

## What is AniOptimizer?

AniOptimizer is a **native C gaming daemon for rooted Android devices**. It eliminates stutter, jank, and thermal throttling in real-time without relying on shell scripts or heavy overhead. The daemon monitors your game's performance and automatically tunes the CPU, GPU, and thermal parameters to maintain smooth gameplay.

## About the Site

The website serves as the central hub for the AniOptimizer project. It provides all the information users need to understand, install, and get support for the tool.

### Key Sections

- **Home:** A quick overview of the project, highlighting the latest version and core statistics (like 0 shell calls and 5ms reaction time).
- **Features:** Detailed breakdowns of the 6 core subsystems, including the Adaptive FSM, Predictive Thermal engine, and Per-Game Learning.
- **Compatibility:** Shows supported SoCs (Snapdragon, Dimensity, Exynos, Tensor) and system requirements (Android 10+, Magisk/KernelSU/APatch).
- **Installation:** A simple 4-step guide to flash the Magisk module and verify the installation.
- **Downloads:** Dynamically fetches and displays the latest releases from the GitHub API, with download links for stable, beta, and alpha builds.
- **FAQ:** Answers common questions about battery usage, custom kernels, conflicts with OEM game modes, and the project's closed-source nature.
- **About:** Displays project info, a live changelog, and links to the GitHub repository, Telegram channel, and latest release.
